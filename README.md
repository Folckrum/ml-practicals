# ML Practicals (LP-III, BE Sem VII)

Clone, `cd` into the practical folder, put the dataset CSV in the same folder, run the script.

Install once: `pip install -r requirements.txt`

| Folder | Practical | Dataset file | Run |
|---|---|---|---|
| 01_uber_fare_prediction | Uber fare, linear regression and random forest | uber.csv | `python uber_fare.py` |
| 02_email_spam_knn_svm | Spam detection with KNN and SVM | emails.csv | `python email_spam.py` |
| 03_bank_churn_neural_network | Bank churn neural network | Churn_Modelling.csv | `python bank_churn.py` |
| 04_diabetes_knn | KNN on diabetes data | diabetes.csv | `python diabetes_knn.py` |
| 05_sales_kmeans_clustering | K-Means with elbow method | sales_data_sample.csv | `python sales_kmeans.py` |
