# ML Practicals (LP-III, BE Sem VII)

Clone the repo, put the dataset CSV in the same folder as the script, then run it.

Install once: `pip install -r requirements.txt`

| File | Practical | Dataset file | Run |
|---|---|---|---|
| uber_fare.py | Uber fare prediction, linear regression and random forest | uber.csv | `python uber_fare.py` |
| email_spam.py | Spam detection with KNN and SVM | emails.csv | `python email_spam.py` |
| bank_churn.py | Bank churn neural network | Churn_Modelling.csv | `python bank_churn.py` |
| diabetes_knn.py | KNN on diabetes data | diabetes.csv | `python diabetes_knn.py` |
| sales_kmeans.py | K-Means with elbow method | sales_data_sample.csv | `python sales_kmeans.py` |
